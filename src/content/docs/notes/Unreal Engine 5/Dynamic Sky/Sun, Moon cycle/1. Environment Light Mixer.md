## EP 1 : Environment Light Mixer
**조명 구성 요소를 중앙에서 관리하는 전용 패널**

```
에디터 상단의 window -> env.Light Mixer로 패널 열기
```

---

### 핵심 개념
환경 라이트 믹서는 다음 5가지 주요 라이트 액터를 통합 관리

| 구성 요소  | 역할 |
| --- | --- |
| **Directional Light** | 태양·달과 같은 주광원  |
| **Sky Light** | 간접광 및 하늘 반사 캡처   |
| **Sky Atmosphere** | 대기 산란 및 스카이 돔 표현 |
| **Volumetric Cloud / Exponential Height Fog** | 안개 및 볼류메트릭 효과 |

📌Tips

```
1. Directional Light의 “Atmosphere / Fog Sun Light” 옵션을 켜야 Sky Atmosphere와 연동됨
2. Sky Light는 Real Time Capture 활성화 시 반사 업데이트가 자동
3. Exponential Height Fog는 조명 방향과 밀도 설정으로 심도감 표현
```

---

### Dynamic Sky - Post process Volume 설정

1. **레벨에 포스트 프로세스 볼륨 추가 및 Infinite Extent 설정**
    - 포스트 프로세스 볼륨: 특정 공간 안에 들어갔을 때 화면에 특수 효과(필터, 색 보정 등)를 적용하는 상자
    - Infinite Extent (Unbound) : 무한 범위 (크기와 상관없이 맵 전체에 이 볼륨의 효과가 적용)
2. **포스트 프로세스 볼륨 노출(Exposure) 설정 - Min EV100 / Max EV100**
    - Max EV100 : 자동 노출이 화면을 최대 얼마까지 밝게 만들 수 있는지 그 한계치를 설정
    - Min EV100 : 자동 노출이 화면을 최소 얼마까지 어둡게 만들 수 있는지 그 한계치를 설정

---

### Auto Exposure
카메라의 밝기 반응을 제어

- 기본값은 자동 노출(Auto Exposure)
- 씬의 밝기 변화에 따라 화면 노출이 자동으로 조정

```
화면에 어두운 부분이 많으면?
- 너무 어둡군. 플레이어가 잘 볼 수 있도록 전체적으로 밝게 만들어야겠다!
- 화면을 자동으로 밝게 보정

반대로 밝은 부분이 많으면?
- 화면을 자동으로 어둡게 만든다
```

---

#### 문제점
라이팅 작업 시 **자동 노출이 켜져 있으면 실제 조명 세기가 고정되지 않는다**

**해결 방법**
```
Post Process Volume의 Exposure 탭에서
    - Min 값: 0.5
    - Max 값: 0.5 (또는 같은 값으로 고정)
```

> Auto Exposure 범위를 없애고 고정된 노출값으로 설정됨


| 항목 | Auto Exposure ON | Auto Exposure OFF |
| 노출 반응  | 씬 밝기에 따라 자동 보정   | 고정값 유지  |
| 라이팅 작업 | 값이 흔들려 정밀 작업 어렵다 | 예측 가능  |
| 적용 방식  | Min/Max 범위 존재    | Min = Max 값으로 고정  |

---

### EV100
**카메라 노출 단위 (Exposure Value at ISO 100)**

- Min EV100 / Max EV100 값은 카메라 노출의 하한과 상한을 의미
- **값이 낮을수록 밝게, 높을수록 어둡게 보인다**

---

### EV100 기본 개념
EV100은 실제 사진/영상의 조리개(f), 셔터 속도(t), ISO를 기준으로 계산된 노출 값

- 공식(ISO 100 기준)

---

$$
EV_{100} = \log_2 \left(\frac{N^2}{t}\right)
$$

---

- N: 조리개 수치 (f-stop)  
- t: 셔터 속도(초)

```
EV100 값이 작을수록 더 많은 빛이 들어온다 (밝다)

EV100 값이 클수록 카메라가 받는 빛의 양이 적다(어둡다)
```
